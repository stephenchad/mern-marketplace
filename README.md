# 🛒 MERN Marketplace

A full-stack multivendor e-commerce marketplace built with the MERN stack.

## Stack
- **Frontend:** React + Vite + TailwindCSS + Redux Toolkit
- **Backend:** Node.js + Express
- **Database:** MongoDB + Mongoose
- **Auth:** JWT + bcrypt
